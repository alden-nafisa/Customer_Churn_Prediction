## 🚀 How to Use

### **1. Install Dependencies**

```bash
cd frontend
npm install
```

### **2. Run Development Server**

```bash
npm run dev
```

App akan jalan di `http://localhost:3000`

### **3. Build for Production**

```bash
npm run build
npm run preview
```
